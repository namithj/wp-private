# Security policy

## Reporting a vulnerability

Please report security problems privately. Do not open a public issue or post in the support forum.

- Email security@smartlogix.co.in
- Once the GitHub repository exists, use GitHub's private vulnerability reporting (the "Report a vulnerability" button on the repository's Security tab).

We acknowledge a report within 3 working days and keep you updated until it is fixed.

## Coordinated disclosure

We follow a 90-day coordinated disclosure window. A fix is released and the advisory published within 90 days of the report, sooner when a fix is ready. We credit reporters who want credit.

## Supported versions

Only the latest release receives security fixes.

| Version | Supported |
|---|---|
| 2.x (latest release) | Yes |
| 1.6.1 and older | No |
